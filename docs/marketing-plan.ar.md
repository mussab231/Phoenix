# خطة التسويق — فينكس (Phoenix)

> مرحلة الطرح: **مجاني أولاً** → بناء قاعدة مستخدمين وتقييمات وثقة → ثم مزايا مدفوعة اختيارية.
> ملاحظة: لا يُذكر فيها أي برنامج منافس بالاسم أبداً — لا في الشاشات، ولا الإعلانات، ولا المراجعات.

## 1) الجمهور المستهدف

| الشريحة | الاحتياج | الرسالة |
|---|---|---|
| طلّاب الجامعة (سوريا/العراق/اليمن/الجزائر/مصر) | ملفات محاضرات، برامج، انترنت ضعيف أو منقطع | "استكمِل بدل ما تبدأ من الصفر" |
| أصحاب الانترنت المحدود(شهري) | انقطاع يضيّع الباقة | أسرع + لا خسارة عند انقطاع |
| المستخدمون العرب على ويندوز | وَاجهة بالعربية | برنامج واجهته عربية ورسمي وكامل |
| المستخدمون غير التقنيين | البساطة | تحميل بنقرة واحدة من المتصفح |

اللغة: العربية أولاً (الانطلاق)، مع الإنجليزية كلغة ثانية.

## 2) العرض (Positioning)

- **الجملة الواحدة**: "مدير تحميلات عربي، سريع، يستكمِل بعد انقطاع النت، ويعمل من المتصفح بدون تثبيت معقّد."
- **التمييز**:
  1. واجهة عربية كاملة باتجاه RTL (لا يوجد منافس يقدمها جاهزة بدقة).
  2. التقاط الروابط من المتصفح مباشرة (إضافة → يمين → "أرسل إلى فينكس").
  3. لا يعتمد على متصفح أو متجر معيّن (`phoenix://` + خادم محلي + حافظة).
  4. مثبّت بدون صلاحيات إدارية، بدون إعلانات، بدون جمع بيانات.

## 3) مراحل الطرح

### المرحلة 0 — التحضير (قبل الإطلاق)
- [ ] لقطات شاشة عربية جذابة (يُضاف إلى `docs/screenshots/`).
- [ ] مثبّت رسمي (Inno Setup) موقّع إن أمكن.
- [ ] صفحة هبوط عربية `docs/landing.ar.md` تُنشر على صفحة GitHub / موقع بسيط.
- [ ] فيديو تجريبي أقصى 60 ثانية.

### المرحلة 1 — الإطلاق المجاني (أسبوع 1–2) 🎉
- النشر على:
  - تجمّعات تيليجرام التقنية العربية المتخصصة بالبرامج والوصلات.
  - جروبات فيسبوك "سوفت وير/تطبيقات" المستهدفة.
  - صفحة GitHub Release مع شرح عربي + لقطات.
- **حافز أول المراجعات**: "جربوا وأعطونا تقييمكم، كل ملاحظة تُنفَّذ" — هدف: أول 20–50 مستخدماً يبلغوا عن مشاكلهم الحقيقية.

### المرحلة 2 — بناء الثقة (أسبوع 3–8)
- شارة **CI باللون الأخضر** + اختبارات ذاتية موثقة → دليل جودة.
- استطلاع قصير (3 أسئلة) لمستخدمي الطور الأول: أين الحمل؟ ما الذي يُكملون تحميله فعلاً؟
- إصلاح أولويات المستخدم (لا أولويات المطوّر).
- (اختياري) صفحة ويب بسيطة: تحميل + الأسئلة الشائعة + معلومات الخصوصية.

### المرحلة 3 — التوسع (شهر 2–3)
- إصدار تحديثات منتظمة بصيغة "سجل التغييرات" بالعربية.
- طلب مراجعات/تقييمات من المستخدمين الراضين عند كل تحديث.
- التعاون مع صانعي محتوى تقني عرب (مؤثّرو برامج) لإلقاء نظرة صادقة.

## 4) خطة المراجعات (Reviews)

المبدأ: **لا مراجعات مفبركة** — تقييمات حقيقية من مستخدمين حقيقيين.

- آلية الطلب: عند إغلاق البرنامج بعد إنجاز أول 3 تحميلات، نافذة لطيفة: "هل أعجبك فينكس؟ قيّمه" (روابط إلى GitHub).
- الرد على كل تعليق سلبي خلال 48 ساعة (ثقة عامة).
- عرّف "رقم سعيد": مثلاً "شكراً لكل من ساعد في النسخة المجانية" في صفحة الإصدار.

## 5) خطة الدخل (يُطبَّق لاحقاً، بعد قاعدة المستخدمين)

**النموذج: Free التحديثات الأساسية + Pro مزايا إضافية** (لا ضرورة لعفى على المزايا الأساسية):

| ميزة Pro المقترحة (مثال) | نموذج الدخل |
|---|---|
| تحميل من عدة مصادر للملف نفسه بنفس الوقت | دعم عالي الأولوية |
| مزامنة قائمة التحميلات بين الأجهزة (حساب بسيط) | اشتراك رمزي شهري |
| إزالة حد التقاط الروابط اليومي (حد مجاني خفيف) | اشتراك مدى الحياة مرة واحدة |

قواعد صارمة:
- **الميزات الأساسية (استكمال/مقاطع/حمولة/عربة) تبقى مجانية للأبد** — هذه سمعة المنتج.
- لا إعلانات، لا تتبع. الخصوصية جزء من العرض.
- الدعم: تيليجرام الرسمي + صفحة أسئلة شائعة.

## 6) قياس النجاح (KPIs)
- التحميلات: عدد تنزيلات المثبّت.
- النشاط: تحميلات المميزة/يوم لكل مستخدم.
- الاستكمال: معدّل اكتمال التحميلات بعد انقطاع (اختبار جودة).
- الرضا: تقييمات GitHub والردود على التعليقات.

## 7) الحماية والالتزام
- الكود شخصي (أرخص رخصة)، لا يُعدّل الطرف الثالث إلا بإذن.
- لا يُنشر الكود المصدر في النسخة المجانية الموزعة إلا ما يقتضي البروتوكول.
- أي ميزة تحاكي اسم منافس أو شعار — ممتنع.
