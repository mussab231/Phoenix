# فينكس 🐦‍🔥 — مدير التحميلات

[![CI](https://github.com/mussab231/Phoenix/actions/workflows/ci.yml/badge.svg)](https://github.com/mussab231/Phoenix/actions/workflows/ci.yml)

**فينكس** برنامج تحميل سريع ومجاني لويندوز، مكتوب بلغة **C++17** ومبني على **WinHTTP** و **Qt6**.
يقسّم الملف إلى مقاطع متوازية لتحميل أسرع، ويستكمِل التحميل تلقائياً بعد الإيقاف أو انقطاع النت — بدون فقدان التقدم.

> 🇬🇧 English README: [README.md](README.md)

## 🖥️ المتطلبات

- ويندوز 10/11 (64-بت)
- للبناء من الكود: [MSYS2](https://www.msys2.org/) مع MinGW-w64 و Qt6 (لا حاجة للمستخدم العادي)

## 📦 التثبيت (للمستخدم)

1. حمّل **النسخة المجانية** من صفحة الإصدارات (مثبّت `.exe` أو نسخة محمولة `portable.zip`).
2. شغّلها — سيعمل رابط `phoenix://` تلقائياً بعد أول تشغيل (تسجيل على مستوى المستخدم، بدون صلاحيات إدارية).
3. أضف الملحق للمتصفح (اختياري، للمتصفحات المستندة إلى Chrome/Edge) من `tools/native/`:
   - افتح `chrome://extensions` → فعّل **Developer mode** → **Load unpacked** → اختر مجلد `tools/native/extension`.
   - فعّل من البرنامج: الإعدادات → "مراقبة الحافظة للروابط" (أو من قائمة العلبة).
4. من العلبة أو الإعدادات: فعّل "البدء مع ويندوز" إن أردت.

## 🔨 البناء من الكود

```powershell
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release "-DCMAKE_PREFIX_PATH=C:/msys64/mingw64"
cmake --build build
```

## 📦 تحضير نسخة الإصدار (مثبّت / محمولة)

```powershell
.\tools\release\build-release.ps1
# الناتج: dist\Phoenix-0.9.0-portable.zip
# ولو عيّنت متغير البيئة ISCC إلى مسار Inno Setup 6، سيبني أيضاً:
# dist\Phoenix-0.9.0-setup.exe
```

| الاختبار | الأمر |
|---|---|
| فحص سريع HEAD + GET | `Phoenix.exe --self-test` |
| تحميل 10MB عبر 8 اتصالات | `Phoenix.exe --self-test-mt` |
| استكمال بعد إيقاف قسري | `Phoenix.exe --self-test-resume` |
| قائمة تحميلات متوازية | `Phoenix.exe --self-test-queue` |
| جدولة + سرعة محدودة + إعادة المحاولة | `--self-test-schedule` / `--self-test-limit` / `--self-test-retry` |
| كاشف الروابط + بروتوكول + إعدادات + سنتير | `--self-test-listen` / `--self-test-proto` / `--self-test-settings` / `--self-test-native` |

## 📝 ملاحظات التصميم

- **WinHTTP + Winsock أصلياً** لويندوز، والواجهة بـ Qt6 فقط — المحرك C++17 صافٍ ومُختبر بالكامل بدون واجهة.
- **الاستكمال عبر ملف حالة جانبي** (`.phoenix-state`): الإيقاف أو الانقطاع أو قتل البرنامج لا يضيّع التقدم.
- **ثلاث قنوات لالتقاط الروابط** حتى لا يعتمد البرنامج على متصفح معيّن.
- **اختبار ذاتي لكل ميزة**: نفس الملف يعمل على جهازك وعلى CI دون شاشة.

## 📄 الرخصة

خاص — **جميع الحقوق محفوظة** (لا ملف رخصة). يمكنك تصفّح الكود وتجربته شخصياً، لكن **لا يُسمح** بإعادة التوزيع أو البيع أو إعادة الاستخدام كلياً أو جزئياً دون إذن كتابي من المؤلف.
